# Every case replayed by scripts/parity.sh must resolve to exactly one block
# below; a case with no block, or with two blocks at the same specificity, is a
# corpus defect and `openkey replay --scope` exits 2. A block is *defined* here
# from day one and *activated* by an `active:` name once its task starts — so
# nothing silently disappears and a green run can only mean "nothing declared is
# unjudged".

# Grammar: `block: <name> <selector>[,<selector>...]`, `#` starts a comment.

# (matched as a path suffix). The most specific match decides; ties are errors.
#
# `--full` selects the file set, never this set: an inactive block is skipped on
# every run, nightly included.
#

#   C-002 telex | C-006 edit | C-003 vni | C-004 simple | C-008 opt
